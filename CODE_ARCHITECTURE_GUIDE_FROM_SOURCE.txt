8) HOW THE APP WORKS END-TO-END (REQUEST FLOW)
============================================================

User opens app
-> /src/app/page.tsx checks AuthContext state
-> routes to login/onboarding/home/teacher pages

On student home
-> /src/app/(main)/home/page.tsx fetches /api/intelligence/student
-> API composes data via Firestore helpers + ML bridge + ADK logic
-> returns StudentIntelligence JSON
-> LearningStateCard/TopicMasteryGrid/graph components render

When user interacts
-> client eventTracker batches events (offline-capable)
-> /api/activity/log persists logs and session metrics

When user asks AI/chat/quiz/syllabus
-> server actions call Genkit flows
-> responses returned to client with fallback behavior where implemented
