# TypeScript Rules

1. **Strict Types & Validation:**
   - Always use `Functional Components`.
   - Strictly `NO any` types allowed.
   - Use `Zod` for all runtime data validation, especially near API ingestion.
   - All integrations must adhere strictly to `src/core/` interface contracts.

2. **Frontend & Engagement Focus:**
   - Every UI component generated must be highly engaging. 
   - Use dynamic visual cues: micro-animations, glassmorphism, responsive layout, dark-mode aesthetics.
   - The primary metric of frontend success is retaining the user's attention.

3. **Privacy First:**
   - Never log or leak PII.
