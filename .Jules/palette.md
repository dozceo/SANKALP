## 2026-06-03 - [Accessibility] Fix icon-only buttons missing aria-labels
**Learning:** The custom Radix A11y violation scanner (`scripts/audit-radix-a11y.ts`) evaluates `icon-button-label` violations line-by-line using basic text matching rather than parsing an AST. When adding an `aria-label` to a Shadcn UI `<Button>` with `size="icon"`, the `aria-label` attribute must be placed on the exact same line as the `size="icon"` declaration to pass the audit.
**Action:** When working on similar accessibility tasks in this repository, always place `aria-label` directly next to `size="icon"` on the same line.
