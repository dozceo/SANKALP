## 2024-05-14 - Add Accessible Clear Button to Inputs
**Learning:** For text search inputs where users frequently type and clear queries, an explicitly coded "clear" button inside the input area is much more accessible than relying solely on the browser's built-in (and often inconsistent or unstylable) clear functionality. It provides a larger tap target, consistent style, keyboard focusability, and screen reader announcements.
**Action:** Always wrap text inputs in a relative container when adding an absolute positioned clear icon. Use `useRef` to programmatically refocus the input after clearing. Make sure the clear button is `type="button"`, has an `aria-label`, focus-visible styles, and an `aria-hidden="true"` icon. Add right padding to the input so text doesn't overlap the clear button.
