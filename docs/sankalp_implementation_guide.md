## SECTION 5: VISUAL CONSISTENCY GUIDELINES

### Color Usage Rules:

**Primary Colors in Images:**
- Trust Blue: 20-30% of image composition (headers, important elements)
- Growth Green: 15-25% (progress indicators, positive moments)
- Warm Orange: 10-15% (engagement, energy, highlights)
- Dark Navy: For text overlays only
- Light Gray: Neutral backgrounds

**Social Media Color Adjustment:**
- Increase saturation by 10-15% for digital
- Slightly increase contrast for small screens
- Ensure text remains legible

**Print Color Adjustment:**
- Reduce saturation by 5-10% for paper (avoid oversaturation)
- Increase contrast for smaller fonts
- Test CMYK separation if printing

### Typography Pairing (If Adding Text):
- Headers: Bold sans-serif (Montserrat, Inter, Poppins)
- Body: Clean sans-serif (Open Sans, Roboto)
- Never more than 2 typefaces
- Maintain 1.5x line spacing for readability
- Minimum 14pt for body text
