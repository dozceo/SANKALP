# Explainability Tooltip Content Drift Analysis (Task 14)

## Overview
This report analyzes the synchronization between the underlying ML/ADK decision logic and the user-facing explanations provided via tooltips and UI text. The goal is to identify "drift" where the explanation does not accurately reflect the true reason for a decision.

## Findings

### 1. Disconnect in Smart Revision Planner Explanations
**Severity:** High
**Location:** `src/ai/flows/smart-revision-planner.ts`
**Issue:** The system uses a two-step process where the ADK (Adaptive Decision Kernel) makes revision decisions based on rich signals, but the explanation is generated by an LLM with limited context.

**ADK Decision Context (Rich Signals):**
The ADK logic in `makeRevisionDecisions` utilizes:
- `days_since_last_revision`: Critical for Spaced Repetition logic.
- `attempts_count`: Indicates effort/persistence.
- `performance_trend`: Indicates if the student is improving or declining.
- `mastery_probability`: ML prediction.

**LLM Explanation Context (Limited Signals):**
The LLM prompt (`explanationPrompt`) is only provided with:
- `topic`: The topic name.
- `mastery`: The predicted mastery percentage.
- `priority`: High/Medium/Low.

**The Drift:**
The LLM is asked to provide reasons focusing on "Spaced repetition benefits", "Building confidence", etc., without knowing the actual values that triggered the decision.
- **Example Scenario:** A student has high mastery (90%) but hasn't revised in 30 days. The ADK flags this for "Spaced Repetition". The LLM sees "Topic (mastery: 90%, priority: HIGH)". It might generate a reason like "Keep your streak up!" or "Mastery is high, let's perfect it!", missing the core reason (Spaced Repetition due to time elapsed).
- **Example Scenario:** A student has low mastery (40%) and declining trend. The ADK flags "Urgent Revision". The LLM sees "Topic (mastery: 40%, priority: HIGH)". It might say "Spaced repetition is key!" even if the student just studied it yesterday (but failed), where the real reason is "Performance Trend Declining".

### 2. Static Tooltips in Learning State Card
**Severity:** Low
**Location:** `src/components/LearningStateCard.tsx`
**Issue:** The tooltip text is static: *"Based on your recent quiz performance, revision gaps, and ML predictions."*
**Analysis:** This static text is broad enough to be generally accurate. However, it does not dynamically adjust to the specific reason for *this specific* state. If a student is in a "Warning" state solely due to lack of activity (not performance), the mention of "quiz performance" might be slightly misleading, but it is not a major drift.

## Recommendations
1.  **Enrich LLM Context:** Pass the specific `reason_code` or `trigger_signal` from the ADK decision (e.g., "SPACED_REPETITION_DUE", "MASTERY_DROP", "TREND_DECLINING") to the LLM prompt.
2.  **Structured Explanations:** Instead of relying on the LLM to hallucinate a reason, use a deterministic mapping for the primary reason, and use the LLM only to *phrase* it naturally.
3.  **Update Tooltips:** Update the `LearningStateCard` tooltip to reflect the primary factor driving the current state (e.g., "Primarily based on your revision gaps").
