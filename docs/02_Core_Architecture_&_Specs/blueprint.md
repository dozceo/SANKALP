# **App Name**: CognitoLearn

## Core Features:

- Brain Map Dashboard: Interactive syllabus graph with progress nodes (red/yellow/green).
- Smart Revision Planner: AI-powered daily list auto-generated via spaced repetition; suggests revisions.
- Adaptive Quiz Engine: 2-5 min quizzes; results update Brain Map. Generative AI selects questions.
- Multilingual Cognitive Chatbot: Anchored to Brain Map to explain concepts.
- Offline-First Mode: Caches the next 3-5 days of revision content.
- Teacher Risk Dashboard: Class heatmap of weak spots and predicted dropout probability.
- Analytics Export: CSV/PDF reports for principals/admin.

## Style Guidelines:

- Primary: #337AB7 for calm intellect.
- Background: #F0F4F8 for clean interface.
- Accent: #5A5FDA to highlight interactive elements.
- Body: 'PT Sans' (sans-serif) for modern readability.
- Headline: 'Playfair' (serif) for elegant headlines.
- Simple, geometric icons.
- Subtle transitions and feedback animations.
