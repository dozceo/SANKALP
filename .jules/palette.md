## 2024-05-19 - Accessibility pattern for neomorphic icon buttons
**Learning:** Found a recurring pattern in the app's custom UI where icon-only buttons using `material-symbols-outlined` spans lack `aria-label`s on the button and `aria-hidden="true"` on the icon itself. Additionally, custom `.neumorphic-flat` buttons lack focus indicators for keyboard navigation, making them inaccessible.
**Action:** When working with custom icon buttons in this codebase, always pair `aria-label` on the parent `<button>` with `aria-hidden="true"` on the inner icon `<span>`. Explicitly add Tailwind's `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-primary focus-visible:ring-offset-2 ring-offset-background` to all custom buttons to ensure focus states are clearly visible for keyboard users.
