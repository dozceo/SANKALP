## 2024-05-17 - Clear Button Accessibility
**Learning:** When adding a clear button inside a search input, it's critical to add `pr-10` to the input to prevent text overlap, and to ensure the button has `type="button"`, `aria-label`, and `focus-visible` styles for keyboard navigation.
**Action:** Always include these accessibility and layout attributes when implementing inline input actions to ensure a smooth, accessible experience.
