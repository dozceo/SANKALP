## 2026-05-21 - Add accessibility labels to dynamic list inputs\n**Learning:** Dynamic list inputs need group labels and individually numbered `aria-label`s for screen readers to announce them properly.\n**Action:** Always wrap dynamic list inputs in a container with `role="group"` and `aria-labelledby` pointing to the group label's ID. Add unique `aria-label` attributes to each individual `<Input>` and action `<Button>` using their index to guarantee proper screen reader accessibility.
